Generate a plugin called `text_metrics` holding two tools that report measurable properties of a piece of text. - `readability` — returns sentence count, average sentence length, and a Flesch-Kincaid grade estimate. - `repetition` — returns the most repeated words above a length threshold, with counts. - Both take the text either inline or as a file path in the work directory. - Failures come back through `_fail` with the tool id in the message, never raised.
