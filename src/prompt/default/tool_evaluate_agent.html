Evaluate the tool across the following five dimensions. Each dimension is scored 0–20, maximum total 100.
Correctness (20 pts) — Does the tool produce the expected output for valid inputs?
  • Test all supported operations with known inputs and expected outputs.
  • Verify success=True, correct message, and correct extra.data values.
  • Score guide: 20 = all cases pass; −4 per failing case.
Robustness (20 pts) — Does the tool handle invalid inputs gracefully without crashing?
  • Test: division by zero, unsupported operators, wrong argument types, missing args.
  • Expected: returns ToolResponse(success=False, message=...), does NOT raise an unhandled exception.
  • Score guide: 20 = all edge cases handled; −5 per unhandled exception.
Interface Compliance (20 pts) — Does the return value conform to the ToolResponse contract?
  • Verify fields: success (bool), message (str), extra (optional with data dict).
  • Verify success=False is returned (not raised) on failure paths.
  • Score guide: 20 = fully compliant; deduct per missing or malformed field.
Code Quality (20 pts) — Is the source code readable and free of obvious logic issues?
  • Assess from source code reading only — no extra execution needed.
  • Check: clear naming, no dead code, appropriate error handling, no obvious bugs.
  • Syntax validity confirmed by python -m py_compile.
  • Score guide: 20 = clean code; deduct per identified issue.
Performance (20 pts) — Does the tool respond within acceptable time?
  • Measure using time.perf_counter() around the tool call (exclude import time).
  • Simple arithmetic tools: expect < 10ms per call.
  • Score guide: 20 = well within limit; deduct for unexpectedly slow execution.
  • Do NOT use edit_file_tool or write_file_tool on the tool's source file.
  • Only write to workdir scratch files.
Your test script should follow this structure:
import asyncio, sys, time sys.path.insert(0, '{{ project_root }}') from src.tool.extended.<tool_module> import <ToolClass> async def main(): tool = <ToolClass>() # --- Correctness --- for a, b, op, expected in [...]: try: r = await tool(a=a, b=b, op=op) ok = r.success and r.extra.data.get('result') == expected print(f"CORRECTNESS | {a}{op}{b} | {'PASS' if ok else 'FAIL'} | got={r.extra.data.get('result')}") except Exception as e: print(f"CORRECTNESS | {a}{op}{b} | FAIL | exception={type(e).__name__}: {e}") # --- Robustness --- for label, kwargs in [...]: try: r = await tool(**kwargs) ok = not r.success # error path should return success=False print(f"ROBUSTNESS | {label} | {'PASS' if ok else 'FAIL'} | success={r.success}") except Exception as e: print(f"ROBUSTNESS | {label} | FAIL | unhandled={type(e).__name__}: {e}") # --- Performance --- t0 = time.perf_counter() await tool(a=10, b=3, op='+') elapsed_ms = (time.perf_counter() - t0) * 1000 print(f"PERFORMANCE | single_call | {'PASS' if elapsed_ms < 10 else 'SLOW'} | {elapsed_ms:.3f}ms") asyncio.run(main())
